First-choice action trigger; a fully-rounded pill. Use `primary` for the single main action on a screen, `secondary`/`tertiary` for supporting actions, `ghost` for low-emphasis, `error` for destructive.

```jsx
<Button variant="primary" size="large" iconLeft="plus" fullWidth>Leave a review</Button>
<Button variant="secondary">Get directions</Button>
<Button variant="ghost" iconRight="chevron-right">See all</Button>
```

Variants: `primary` (filled green) · `secondary` (outlined) · `tertiary` (soft tint) · `ghost` (text) · `error`. Sizes: `small` (32) · `medium` (40) · `large` (48). Props: `iconLeft` / `iconRight` take an icon name, `disabled`, `fullWidth`.
